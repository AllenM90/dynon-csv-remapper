# dynon-csv-remapper

Simple Go + Fyne desktop tool to remap Dynon EMS CSV headers for Savvy Aviation upload.

## Features (MVP)
- Editable config.json for header mappings
- Native file pickers
- One-click process

## Build & Run
```bash
go mod tidy
go run main.go
```
